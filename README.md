# Felsefi Asansör Bekleyicisi

## Bu Proje Nedir?

Bu, insanlık tarihinin en ciddi ve en gereksiz yazılım projesidir. Asansör beklerken yaşanan varoluşsal krizleri simüle eder. Gerçekten çalışır. Kod sonsuz döngüdedir. Asansör asla gelmez. Tıpkı hayat gibi.

### Neden Var?

Çünkü biri "asansör beklerken ne düşünürsün?" diye sordu. Cevap: Felsefe. Ve bu repo.

### Nasıl Çalıştırılır?

```bash
python3 asansor_bekleyicisi.py
```

Sonra bekle. Bekle. Bekle. Ctrl+C ile kurtulabilirsin ama asansör gelmeyecek.

### Özellikler

- %100 gerçek felsefi mesajlar
- Rastgele bekleme süreleri (1.5-4 saniye)
- Sonsuz döngü (asansör gelmez)
- Patates içermez (önemli)
- Abartılı ciddiyet

### Katkıda Bulunma

Yapma. Bu proje mükemmel. Dokunma. Asansör beklemeye devam et.
